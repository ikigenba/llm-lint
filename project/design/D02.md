# Decision 2 — Configuration resolution

**Decision.** Package `internal/config`.

```go
type Config struct {
    Root     string   // directory of the found config file, else cwd
    Enable   []string // allowlist of rule ids; empty means every rule is active
    Disable  []string // rule ids to silence, subtracted from the active set
    Rules    []string // local rule files/dirs, relative to Root
    Exclude  []string // global path globs, relative to Root
    Model    Model    // resolved model settings
    Warnings []string // non-fatal notices for run to print once to stderr
}

type Model struct {
    Provider, ModelID, BaseURL string
    ProviderExplicit           bool   // provider was set, not derived
    Auth                       string // "" (default per provider), "key", or "sub"
    AuthFile                   string // token file for auth=sub; "" means the default path
    Temperature, TopP          *float64
    MaxTokens                  int
    Reasoning                  agentkit.ReasoningValue
    Retry                      agentkit.RetryPolicy
}

func Load(cwd string, cliPairs []string, getenv func(string) string) (*Config, error)
func (c *Config) NewConversation(system string, log io.Writer) (*agentkit.Conversation, error)

// The provider table — the authority for the six providers, their env keys,
// and their auth methods (first entry is the default when auth is unset).
// Rendered by the --help catalog (D01) and consulted during resolution.
type ProviderSpec struct {
    EnvKey  string
    Methods []string // "key" and/or "sub"; Methods[0] is the default
}
func Providers() []agentkit.ProviderID              // stable display order
func ProviderInfo(id agentkit.ProviderID) (ProviderSpec, bool)
```

Provider table (mirrors agent-repl verbatim):

| provider | env key | methods (first = default) |
|---|---|---|
| `anthropic` | `ANTHROPIC_API_KEY` | key |
| `google` | `GEMINI_API_KEY` | key |
| `openai` | `OPENAI_API_KEY` | sub, key |
| `openrouter` | `OPENROUTER_API_KEY` | key |
| `x-ai` | `XAI_API_KEY` | sub, key |
| `z-ai` | `ZAI_API_KEY` | key |

`Load` walks from `cwd` upward to the filesystem root looking for
`.llm-lint.json`; the first hit wins and its directory becomes `Root`. No
config file is not an error: defaults apply and `Root` is `cwd`. The file is
strict JSON with keys `enable`, `disable`, `rules`, `exclude`, and `model` —
the model object using agent-repl's flat key names (`provider`, `model`,
`temperature`, `top_p`, `max_tokens`, `effort`, `thinking_budget`,
`thinking_level`, `thinking`, `max_attempts`, `base_delay`, `max_delay`,
`max_elapsed`, `ignore_retry_after`, `base_url`, `auth`, `auth_file`). `-c
key=value` pairs address the same flat model keys and override the file; the
literal value `default` resets a key to unset. Unset model defaults to
`gemini-3.7-flash`. Setting `provider` marks `ProviderExplicit`.

**Selection is agent-repl's, verbatim; validity is agentkit's, not the
catalog's.** The catalog is consulted for exactly two things: rendering the
`--help` model list (D01) and *deriving a default provider* for a bare
`model=`. It never decides whether a provider+model combination is allowed.

- **Bare `model=` (no explicit provider):** the provider is derived from the
  catalog's curated offering for the model (`catalog.Resolve` with empty
  provider). A model the catalog does not know has no derivable provider and is
  rejected — `ErrConfig` telling the user to set a provider explicitly. (Every
  curated model carries a provider, so a curated model always derives one; the
  default `gemini-3.7-flash` derives `google`.)
- **Explicit `provider=`:** the provider is used as given and derivation is
  skipped. Any model — curated for that provider or not — is sent. A model not
  curated for the provider is a **pass-through**: the conversation is built with
  the raw model string as `WireModel` and no `Pricing` (cost reports 0), and a
  one-time warning ("no pricing (cost reports 0), reasoning unchecked") is
  appended to `Config.Warnings`. It is **not** an error; whether the model
  actually works is decided by agentkit when the message is sent (D05): a
  provider rejection surfaces as an operational failure (exit 3), never a
  silent success.

**Auth.** `auth` selects the credential mode; unset means the provider's
default (`Methods[0]` — `sub` for openai/x-ai, `key` for the other four). An
`auth` value other than `key`/`sub` is `ErrConfig`. `auth=sub` on a provider
whose `Methods` lacks `sub` (anything but openai/x-ai) is `ErrConfig` naming the
provider as key-only. These are the pre-send config rejections `Load` makes
without touching the network or credentials.

`NewConversation` builds a fresh `agentkit.Conversation` (fresh per call —
conversations retain history) with `Model` = the resolved `WireModel`,
`Pricing` from the catalog (nil for a pass-through), `Log` attached, and a
provider constructed per the resolved auth mode:

- **`auth=key`** — read the provider's env key via `getenv` and build the
  provider with `<pkg>.APIKey(key)`. An unset/empty key is `ErrAuth` naming the
  exact variable.
- **`auth=sub`** — load the token file with `openai/subscription.Load` (or
  `xai/subscription.Load`) and build the provider with
  `<pkg>.Subscription(store)`. The token file is `AuthFile` when set, else the
  default `~/.llm-lint/<provider>-auth.json` (home via `getenv("HOME")`). A
  missing, unreadable, or malformed token file is `ErrAuth` naming the exact
  path.

```go
func defaultAuthFile(getenv func(string) string, id agentkit.ProviderID) string
// -> filepath.Join(getenv("HOME"), ".llm-lint", string(id)+"-auth.json")
```

Error surface (all returned, none panic):

- `ErrConfig` (wrapped, named file/key/reason) → caller exits 2 — malformed
  JSON; unknown top-level or model key; bad value; malformed `-c` pair; a bare
  `model=` unknown to the catalog with no explicit provider; an `auth` value
  that is not `key`/`sub`; `auth=sub` on a key-only provider.
- `ErrAuth` (names the exact env variable or token-file path) → caller exits 3
  — `auth=key` with the env key unset; `auth=sub` with the token file missing,
  unreadable, or malformed.

**Rejected.** YAML/TOML config: JSON is the suite convention (autotune
`config.json`) and needs no dependency. Catalog-coverage as the validity gate:
the catalog is a curated view, not the provider's actual capability — pinning
validity to it would reject working models and forbid the pass-through the user
wants; agentkit's send is the authority. Auto-discovering or minting a
subscription token: `subscription.Load` reads a caller-named file and llm-lint
has no interactive session to run a login, so it only *consumes* a token file
already produced (by `agentrepl`'s login, copied to `~/.llm-lint/`). Config
search stopping at a git root: filesystem-root walk is simpler and matches how
the file is placed (repo root).
