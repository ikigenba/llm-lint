# Decision 2 — Configuration resolution

**Decision.** Package `internal/config`.

```go
type Config struct {
    Root     string   // directory of the found config file, else cwd
    Enable   []string // allowlist of rule ids; empty means every rule is active
    Disable  []string // rule ids to silence, subtracted from the active set
    Rules    []string // local rule files/dirs, relative to Root
    Exclude  []string // global path globs, relative to Root
    Model    Model    // resolved model settings
}

type Model struct {
    Provider, ModelID, BaseURL string
    Temperature, TopP          *float64
    MaxTokens                  int
    Reasoning                  agentkit.ReasoningValue
    Retry                      agentkit.RetryPolicy
}

func Load(cwd string, cliPairs []string, getenv func(string) string) (*Config, error)
func (c *Config) NewConversation(system string, log io.Writer) (*agentkit.Conversation, error)
```

`Load` walks from `cwd` upward to the filesystem root looking for
`.llm-lint.json`; the first hit wins and its directory becomes `Root`. No
config file is not an error: defaults apply and `Root` is `cwd`. The file is
strict JSON with keys `enable`, `disable`, `rules`, `exclude`, and `model` — the model
object using agent-repl's flat key names (`provider`, `model`, `temperature`,
`top_p`, `max_tokens`, `effort`, `thinking_budget`, `thinking_level`,
`thinking`, `max_attempts`, `base_delay`, `max_delay`, `max_elapsed`,
`ignore_retry_after`, `base_url`). `-c key=value` pairs address the same flat
model keys and override the file; the literal value `default` resets a key to
unset. Unset model defaults to `gemini-3.7-flash`; provider defaults to the
catalog's curated provider for the model.

`NewConversation` resolves the model against `agentkit/catalog`, reads the
provider's env key via `getenv`, and builds a fresh `agentkit.Conversation`
(fresh per call — conversations retain history) with `Pricing` from the
catalog and `Log` attached. Auth is env-key only.

Error surface (all returned, none panic):

- `ErrConfig` (wrapped, named file + reason) — malformed JSON, unknown key,
  bad value, malformed `-c` pair → caller exits 2.
- `ErrAuth` (names the exact missing env variable) — provider env key unset
  or model unknown to the catalog → caller exits 3 for a missing key;
  unknown model id is `ErrConfig` (exit 2).

**Rejected.** YAML/TOML config: JSON is the suite convention (autotune
`config.json`) and needs no dependency; rule prose lives in rule files, not
config comments. Auth files / subscription flows: headless CI tool, env keys
only. Config search stopping at a git root: filesystem-root walk is simpler
and matches how the file is actually placed (repo root).

**Verification.**

- R-FZO2-3276 — `Load` from a nested directory finds `.llm-lint.json` in an
  ancestor and sets `Root` to that ancestor.
- R-G0VY-GTXV — absent config file: `Load` succeeds, `Root` = cwd, `Enable`
  and `Disable` both empty, model is the default.
- R-2K92-YDXU — a `disable` JSON string array in `.llm-lint.json` populates
  `Config.Disable` in file order; a non-array or non-string-element `disable`
  value returns `ErrConfig` naming the key.
- R-G23U-ULOK — malformed JSON returns `ErrConfig` naming the file; an
  unrecognized top-level or model key returns `ErrConfig` naming the key.
- R-G3BR-8DF9 — a `-c` model key overrides the same key from the file.
- R-G5RJ-ZWWN — `-c key=default` resets a file-set key to its unset state.
- R-G6ZG-DONC — with no model configured anywhere, the resolved model is
  `gemini-3.7-flash` on the Google provider.
- R-G87C-RGE1 — `NewConversation` with the provider's env key unset returns
  `ErrAuth` whose message contains the exact variable name (e.g.
  `GOOGLE_API_KEY`).
- R-G9F9-584Q — a malformed `-c` pair (no `=`, empty key, unknown key)
  returns `ErrConfig`.
