# Decision 10 — Release and installation

**Decision.** llm-lint releases exactly like ralph/agent-repl:

- `.goreleaser.yaml` (v2): project `llm-lint`, build from `./cmd/llm-lint`,
  binary `llm-lint`, `CGO_ENABLED=0`, `goos: [linux, darwin]`,
  `goarch: [amd64, arm64]`, ldflags `-s -w -X main.version={{ .Tag }}`,
  tar.gz archives named `{{ .Binary }}_{{ .Os }}_{{ .Arch }}`, checksums,
  GitHub release under `ikigenba/llm-lint`, changelog from GitHub.
- `.github/workflows/release.yml`: on `v*` tag push — checkout (full depth),
  setup-go 1.26, `goreleaser/goreleaser-action@v6` with `release --clean`.
- `install.sh` (POSIX sh, ralph's shape): `REPO=ikigenba/llm-lint`,
  `BINARY=llm-lint`, OS/arch detection (linux/darwin, amd64/arm64),
  `LLM_LINT_VERSION` override (default latest), fetch the release asset,
  install into `${BINDIR:-${PREFIX:-$HOME/.local}/bin}`.
- `Makefile` with the suite's usual `build` / `test` / `install` targets.

Version stamping rides D01's `var version = "dev"`; a dev build prints `dev`,
a released build the tag.

**Rejected.** Homebrew tap / OS packages: siblings ship none; the installer
script plus the doctor skill's roster is the suite's distribution story.
Windows builds: no sibling ships them and nothing in the settled scope asks
for one.

**Verification.**

- R-HJRF-OIB4 — a release-consistency test (ralph's `release_test.go`
  pattern) asserts `.goreleaser.yaml`, `.github/workflows/release.yml`, and
  `install.sh` exist and agree on: project/binary/repo name `llm-lint` under
  `ikigenba`, main path `./cmd/llm-lint`, both OS and both arches, the
  archive name template, and the workflow's `v*` tag trigger.
- R-HKZC-2A1T — `install.sh` passes `sh -n` (syntax) and names the
  `LLM_LINT_VERSION` override and the `${BINDIR:-${PREFIX:-$HOME/.local}/bin}`
  destination; the Makefile's `install` target builds and installs the
  `llm-lint` binary.
