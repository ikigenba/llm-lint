# Decision 5 — Inference engine

**Decision.** Package `internal/engine`. One model call per (rule, file) pair.

```go
type Finding struct {
    Rule        string
    Severity    rules.Severity
    File        string // Root-relative
    Line        int    // 1-based
    Evidence    string // exact source line text, taken from the file, not the model
    Explanation string // model's one-sentence reason
}

// Client is the inference seam run() binds; fakes implement it in tests.
type Client interface {
    Judge(ctx context.Context, r rules.Rule, file string, content []byte) ([]Finding, error)
}

type AgentkitClient struct {
    NewConversation func(system string, log io.Writer) (*agentkit.Conversation, error) // from D02
    Log             io.Writer // session JSONL, always attached
}

type Engine struct {
    Client      Client
    Concurrency int // default 8
    Trace       *Trace // nil unless --verbose (D01); records oversize skips
}

// TraceEntry is one (rule, file) pair's audit record for --verbose (D06 fills
// judged pairs, the engine fills skips; D08 renders). Outcome is one of
// "pass" (clean verdict), "fail" (≥1 finding), or "skipped" (oversize, never
// judged). Cached is meaningful only for pass/fail; it is false for skips.
type TraceEntry struct {
    File, Rule string
    Cached     bool
    Outcome    string
}

// Trace is a concurrency-safe sink shared by the engine and the caching
// client; workers Add from the pool, run reads Entries after the run.
type Trace struct { /* mutex-guarded slice */ }

func (t *Trace) Add(e TraceEntry)
func (t *Trace) Entries() []TraceEntry

func (e *Engine) Run(ctx context.Context, rs []rules.Rule, files map[string][]string,
    read func(path string) ([]byte, error), warn io.Writer) ([]Finding, Stats, error)
```

`AgentkitClient.Judge` builds a fresh Conversation per call. The system prompt
frames the task (one rule, one file, judge only this rule); the user message
carries the rule prompt and the file content with 1-based line numbers
prefixed. Structured output uses the suite idiom (research): a single typed
tool `report_violations` registered via `agentkit.NewTool`, whose input is the
violations array `[{line, evidence, explanation}]` (empty array = clean); the
system prompt requires exactly one call to it. A turn that ends without the
tool being called is retried once with a corrective nudge; a second miss is an
operational failure for that pair. `Evidence` is then overwritten with the
actual text of the reported line read from the file (the model's copy is
untrusted); a reported line number outside the file drops that violation with
a stderr warning.

Sizing: before calling, the pair is checked against the model's catalog
context window (bytes/3 heuristic vs. `Entry` context, with headroom for the
rule prompt and output); an oversized file is skipped with a stderr warning
naming file and rule, and does not affect the exit code. When `Trace` is set,
each skipped pair is also recorded as a `TraceEntry{Outcome: "skipped"}` (the
client is never called, so the cache records nothing for it — the engine is the
only layer that sees a skip).

`Engine.Run` fans pairs out over a bounded worker pool (`Concurrency` max in
flight), collects findings, and aggregates `Stats` (pairs judged, calls made,
tokens, cost from `Stream.Usage`/`Cost`, later merged with cache hits by
D06/D08). Provider errors surface via agentkit's `RetryPolicy` first; a pair
still failing is an operational failure.

Error surface: `Judge` returns wrapped provider/parse errors; `Engine.Run`
cancels outstanding work on the first operational failure and returns it
(caller exits 3). Context cancellation propagates. Panics only on programmer
errors (nil Client, Concurrency < 1).

The session log: `run` (D01) opens `~/.agentkit/<session-id>.jsonl`
(agent-repl's convention and id format, directory injectable for tests) and
attaches it as `Log` to every Conversation; it is written unconditionally —
not a flag — and never read back.

**Rejected.** Batching several rules or files per call: couples cache
invalidation across rules and measurably degrades cheap-model verdict quality;
token savings are not worth misfires. Splitting oversized files across calls:
verdict quality across arbitrary split boundaries is dubious and the 400k/1M
contexts make it a rare edge — skip loudly instead. Prose/JSON-mode output
parsing: agentkit exposes no forced JSON mode; the typed tool is the suite
idiom and validates shape at the decode boundary.

**Verification.**

- R-GRPQ-VS95 — with R rules × F candidate files (fake Client), `Engine.Run`
  makes exactly one `Judge` call per (rule, file) pair.
- R-GSXN-9JZU — a fake conversation whose tool call reports `{line,
  evidence, explanation}` yields a Finding with that line, the file's actual
  line text as Evidence, and the rule's severity; a reported line beyond EOF
  drops the violation with a warning.
- R-GU5J-NBQJ — a fake conversation that never calls the tool is retried
  once, then surfaces as an operational failure naming the rule and file.
- R-GVDG-13H8 — with Concurrency=N and more than N pairs, the observed
  maximum in-flight `Judge` count is ≤ N (and > 1 for N > 1).
- R-GWLC-EV7X — a file exceeding the model's context budget is skipped with
  a stderr warning naming file and rule; the run's findings and exit code are
  unaffected.
- R-H40E-2VXC — with a `Trace` set, a pair whose file exceeds the context
  budget adds exactly one `TraceEntry{File, Rule, Outcome: "skipped"}` to the
  trace and makes no `Judge` call for it; with `Trace` nil the same skip adds
  nothing.
- R-GXT8-SMYM — after a run, the session JSONL (in the injected directory)
  exists and contains the raw request/response records of the calls made.
- R-GZ15-6EPB — live (Google, skips without `GEMINI_API_KEY`): the assembled
  binary path (`run` through the real composition root) on a fixture with a
  blatant sleep-past-a-race in a Go test, `no-sleep-in-tests` enabled, default
  model `gemini-3.7-flash` (provider derived, auth=key), reports a finding in
  that file and returns exit 1.
- R-H091-K6G0 — live (OpenAI, skips without `OPENAI_API_KEY`): the same
  fixture judged with `-c model=gpt-5.6-luna -c auth=key` (openai defaults to
  sub, so the key path is selected explicitly) reports the finding, proving
  the second provider path via an env key end-to-end.
- R-J81P-S6MN — live (subscription, skips unless the provider's default token
  file `~/.llm-lint/<provider>-auth.json` exists and loads): the same fixture
  judged with `-c auth=sub` against a sub-capable provider reports the finding,
  proving the real subscription transport (agentkit `Subscription` credential)
  end-to-end, not merely that the credential was constructed.
