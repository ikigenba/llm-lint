# Decision 5 — Inference engine

**Decision.** Package `internal/engine`. One model call per (rule, file) pair.

```go
type Finding struct {
    Rule        string
    Severity    rules.Severity
    File        string // Root-relative
    Line        int    // 1-based
    Evidence    string // exact source line text, taken from the file, not the model
    Explanation string // model's one-sentence reason
}

// Usage is one Judge call's token/cost accounting, reported by the Client on
// the seam so engine never leaks the agentkit usage type to implementers.
// Input is the turn's total input tokens, Output its total output tokens
// (reasoning included), CostUSD the turn's cost in US dollars (0 for a
// pass-through model the catalog has no pricing for). A cache hit reports the
// zero value: no call was made, so it consumes no tokens.
type Usage struct {
    Input, Output int64
    CostUSD       float64
}

// Client is the inference seam run() binds; fakes implement it in tests.
// Judge returns the pair's findings and the call's Usage together.
type Client interface {
    Judge(ctx context.Context, r rules.Rule, file string, content []byte) ([]Finding, Usage, error)
}

type AgentkitClient struct {
    NewConversation func(system string, log io.Writer) (*agentkit.Conversation, error) // from D02
    Log             io.Writer // session JSONL, always attached
}

type Engine struct {
    Client      Client
    Concurrency int // default 8
    Trace       *Trace // nil unless --verbose (D01)
}

// TraceEntry is one judged (rule, file) pair's audit record for --verbose (D06
// fills it, D08 renders). Outcome is one of "pass" (clean verdict) or "fail"
// (≥1 finding). Cached distinguishes a cache hit from a fresh judgement.
type TraceEntry struct {
    File, Rule string
    Cached     bool
    Outcome    string
}

// Trace is a concurrency-safe sink the caching client writes; workers Add from
// the pool, run reads Entries after the run.
type Trace struct { /* mutex-guarded slice */ }

func (t *Trace) Add(e TraceEntry)
func (t *Trace) Entries() []TraceEntry

func (e *Engine) Run(ctx context.Context, rs []rules.Rule, files map[string][]string,
    read func(path string) ([]byte, error), warn io.Writer) ([]Finding, Stats, error)
```

`AgentkitClient.Judge` builds a fresh Conversation per call. The system prompt
frames the task (one rule, one file, judge only this rule); the user message
carries the rule prompt and the file content with 1-based line numbers
prefixed. Structured output uses the suite idiom (research): a single typed
tool `report_violations` registered via `agentkit.NewTool`, whose input is the
violations array `[{line, evidence, explanation}]` (empty array = clean); the
system prompt requires exactly one call to it. A turn that ends without the
tool being called is retried once with a corrective nudge; a second miss is an
operational failure for that pair. `Evidence` is then overwritten with the
actual text of the reported line read from the file (the model's copy is
untrusted); a reported line number outside the file drops that violation with
a stderr warning.

Usage accounting: after draining the stream, `Judge` reads `Stream.Usage()`
and `Stream.Cost()` and returns them as `engine.Usage` (Input from the input
buckets, Output including reasoning output, CostUSD from `Cost().USD()`). It
does not size or pre-check the file against any context window — a file too
large for the model surfaces as an ordinary provider error, which becomes an
operational failure for that pair (exit 3), the same as any other call that
cannot complete.

`Engine.Run` fans pairs out over a bounded worker pool (`Concurrency` max in
flight), collects findings, and aggregates `Stats`: `Rules`/`Files`/`Pairs`
counted from the work set, `Calls` counted per judged pair, and
`InputTokens`/`OutputTokens`/`CostUSD` summed from each pair's returned
`Usage`. Cache hits contribute the zero `Usage` (the caching client, D06,
returns it), so the token/cost totals reflect only real calls; `CacheHits` is
merged in later by D08 from the cache's own counter.

Error surface: `Judge` returns wrapped provider/parse errors alongside a zero
`Usage`; `Engine.Run` cancels outstanding work on the first operational
failure and returns that error `%w`-wrapped (caller exits 3) — the engine
returns only operational failures, so `run` maps any non-nil error to exit 3
without inspecting its type. Context cancellation propagates. Panics only on
programmer errors (nil Client, Concurrency < 1). Provider errors surface via
agentkit's `RetryPolicy` first; a pair still failing is an operational
failure.

The session log: `run` (D01) opens `~/.agentkit/<session-id>.jsonl`
(agent-repl's convention and id format, directory injectable for tests) and
attaches it as `Log` to every Conversation; it is written unconditionally —
not a flag — and never read back.

**Rejected.** Batching several rules or files per call: couples cache
invalidation across rules and measurably degrades cheap-model verdict quality;
token savings are not worth misfires. Pre-sizing files against the model's
context window and skipping oversized ones: the feature never fired correctly
in practice and modern 400k/1M contexts make a genuine overflow a rare edge;
letting an oversized file surface as an ordinary loud operational failure is
simpler and more honest than a silent skip path nothing exercises. A typed
`OpFailure` error the engine returns: no caller branches on the type — `run`
maps every engine error to exit 3 identically — so a wrapped `error` carries
the same information without the ceremony. Prose/JSON-mode output parsing:
agentkit exposes no forced JSON mode; the typed tool is the suite idiom and
validates shape at the decode boundary.

**Verification.**

- R-GRPQ-VS95 — with R rules × F candidate files (fake Client), `Engine.Run`
  makes exactly one `Judge` call per (rule, file) pair.
- R-GSXN-9JZU — a fake conversation whose tool call reports `{line,
  evidence, explanation}` yields a Finding with that line, the file's actual
  line text as Evidence, and the rule's severity; a reported line beyond EOF
  drops the violation with a warning.
- R-GU5J-NBQJ — a fake conversation that never calls the tool is retried
  once, then surfaces as an operational failure naming the rule and file.
- R-GVDG-13H8 — with Concurrency=N and more than N pairs, the observed
  maximum in-flight `Judge` count is ≤ N (and > 1 for N > 1).
- R-ETNZ-VY1Q — with a fake Client returning a known non-zero
  `Usage{Input, Output, CostUSD}` per call over K judged pairs, `Engine.Run`
  returns `Stats` whose `InputTokens`, `OutputTokens`, and `CostUSD` each equal
  K times the per-call value (and are non-zero), proving per-pair usage is
  summed rather than dropped.
- R-GXT8-SMYM — after a run, the session JSONL (in the injected directory)
  exists and contains the raw request/response records of the calls made.
- R-GZ15-6EPB — live (Google, skips without `GEMINI_API_KEY`): the assembled
  binary path (`run` through the real composition root) on a fixture with a
  blatant sleep-past-a-race in a Go test, `no-sleep-in-tests` enabled, default
  model `gemini-3.7-flash` (provider derived, auth=key), run with `--stats`,
  reports a finding in that file, returns exit 1, and prints a `--stats` line
  whose input-token figure is non-zero — proving real usage flows from the
  drained stream through the engine to the report, not merely that the fields
  exist.
- R-H091-K6G0 — live (OpenAI, skips without `OPENAI_API_KEY`): the same
  fixture judged with `-c model=gpt-5.6-luna -c auth=key` (openai defaults to
  sub, so the key path is selected explicitly) reports the finding, proving
  the second provider path via an env key end-to-end.
- R-J81P-S6MN — live (subscription, skips unless the provider's default token
  file `~/.llm-lint/<provider>-auth.json` exists and loads): the same fixture
  judged with `-c auth=sub` against a sub-capable provider reports the finding,
  proving the real subscription transport (agentkit `Subscription` credential)
  end-to-end, not merely that the credential was constructed.
